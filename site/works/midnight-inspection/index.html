Phase 1 完成版

Phase 1は、3Dの廊下を中心に探索と音響を検証する技術プロトタイプです。深夜の東棟で3室を巡回し、扉の向こうの返答や異変を確かめて記録します。入口の報告ポストへ戻ると、記録に応じて2つの結末に分かれます。

BEFORE YOU START

遊ぶ前に

  • macOS版Google Chromeが正式な動作確認対象です。
  • キーボードとマウスを使います。ヘッドホンを推奨します。
  • WebGL 2とWebAssemblyが利用できる環境が必要です。

3室の確認札を調べ、扉の向こうの異変を確かめて記録します。巡回を終えたら、入口の報告ポストへ戻ってください。

Esc・タブ切替・フォーカス喪失で一時停止します。再開するには、ゲーム内の再開ボタンを直接クリックしてください。

進捗の保存機能はありません。ページを再読み込みすると最初から始まります。

FUTURE CONCEPT

今後の構想

昭和の日本家屋を舞台にしたホラーへの発展を構想しています。この舞台はPhase 1には実装していません。

TECH & PROCESS

技術と制作過程

Three.jsで廊下を描き、RapierのWASMで移動と衝突を処理します。環境音やノック、足音はWeb Audioで合成しています。

Three.js 0.186.1Rapier WASM 0.21.0Web AudioTypeScriptVite 8.3.4
  1. Phase 1A–1B

    探索の基盤を作り、移動・衝突・しゃがみ・扉の開閉を実装しました。

  2. Phase 1C

    空間音響、遮音、聞き耳、扉の向こうの怪異を追加しました。

  3. Phase 1D

    3室の巡回記録、報告、2つの結末、再巡回を追加し、Phase 1を完成させました。
